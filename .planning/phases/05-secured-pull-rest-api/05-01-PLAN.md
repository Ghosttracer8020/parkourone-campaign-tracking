## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Spoofing | `POT_Api::check_bearer` | mitigate | Real `permission_callback` reads `Authorization: Bearer`, compares with `hash_equals` after length pre-check; NEVER `__return_true`. Verified by grep: no `__return_true` in non-comment code, `hash_equals` present. An open endpoint here is a HIGH-severity blocker. |
| T-05-02 | Information disclosure | bearer compare / error path | mitigate | Identical generic 401 message for missing/empty/wrong secret (does not reveal whether a secret exists); secret never `error_log`'d/echoed; length pre-check before hash_equals so compare never throws. |
| T-05-03 | Information disclosure (timing) | bearer compare | mitigate | Length pre-check + `hash_equals` constant-time compare (mirrors helper-functions.php:123); plain `===` on the secret is forbidden. |
| T-05-04 | Tampering / Injection | `from`/`to` args + gateway | mitigate | `validate_callback` (Y-m-d / ISO-8601) + `sanitize_text_field` at the route boundary; aggregation only via `POT_Store::aggregate_by_campaign` `$wpdb->prepare`; API contains NO `$wpdb`/SELECT (grep-verified). |
| T-05-05 | Information disclosure (data minimization) | payload | mitigate | Endpoint returns ONLY per-campaign aggregates (counts + rates) — no raw events, no IP/UA/PII. Raw-event export is explicitly out of scope. |
| T-05-06 | Information disclosure (CORS) | response headers | mitigate | No `Access-Control-Allow-Origin` header is sent (grep-verified absent); the pull is server-to-server, not browser-CORS. |
| T-05-07 | Denial of service | range span | accept | 366-day span cap bounds query cost; single GROUP BY over composite indices; low-value read-only target, no write amplification. |
| T-05-SC | Tampering | npm/pip/cargo installs | n/a | No package-manager installs in this phase (pure PHP, no new dependencies). |
</threat_model>
