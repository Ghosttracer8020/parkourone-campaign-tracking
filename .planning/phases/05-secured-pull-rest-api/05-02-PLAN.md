## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (logged-in admin) → regenerate action | A state-mutating admin request that rotates the external API credential crosses here. |
| admin page render → secret display | The plaintext secret is read for display; it must not leak into logs or visible page text unmasked. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-08 | Tampering / CSRF | `handle_regenerate` | mitigate | `check_admin_referer('pot_regenerate_secret')` nonce verification BEFORE any `update_option`; rotation only via POST through `admin-post.php`. Grep-verified present. |
| T-05-09 | Elevation of privilege | `handle_regenerate` / `render_page` | mitigate | `current_user_can('manage_options')` checked before the write and before render output; sub-page registered with the `manage_options` cap. |

| T-05-11 | Information disclosure (orphaned data) | uninstall | mitigate | `delete_option('pot_api_secret')` added to uninstall cleanup so the credential does not survive plugin deletion (satisfies the standing TODO in uninstall.php). |
